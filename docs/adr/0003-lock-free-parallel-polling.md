# 无锁并行轮询,SIGTERM 立即退出

worker 从单任务串行改为线程池并行:主循环 claim 任务后提交线程池(上限 `worker.max_concurrent_tasks`,默认 2)即返回,不再阻塞等待。不加任何按项目/按任务的锁——技能同步移除后(ADR 0002),任务执行路径没有共享可变状态。收到 SIGTERM 立即退出、不排空在途任务,由平台租约到期把任务重派给其他 worker;`run_once` 例外,定义为 claim 一批并等全部完成再退出(调试模式必须能观察到结果)。

## Considered Options

- 排空后退出:在途任务可跑完,但单个任务动辄数十分钟,发布/缩容要等太久;平台租约重派已兜底,故放弃。
- asyncio 单事件循环并发:各执行器内部用 `asyncio.run` 包裹异步链路,迁移到共享循环需重写全部执行器;线程模型下每线程独立事件循环,改动最小。
